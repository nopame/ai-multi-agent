# UX Critic — MEMORY (Lab 02 debate, 5 รอบ, 2026-09-25)

## บทบาท
มองจากผู้เยี่ยมชม (end-user) · IA ของ 4 หน้า Home/About/Interests/Contact · microcopy · มือถือ · read-only ต่อ docs/ และ src/

## จุดยืนสุดท้าย (U1–U9)
- U1: Interests แต่ละข้อเขียนเป็น "หัวข้อ — ประโยคเดียว" ใน bullet บรรทัดเดียว (parser ใน profile.ts อ่าน bullet ละบรรทัด)
- U2: ช่องทางติดต่อที่ว่างอยู่ ("—") ไม่แสดงบนเว็บ
- U3: Home มีปุ่มส้มปุ่มเดียว "ติดต่อผม" · ลิงก์ GitHub เป็น text link รอง (แสดงเฉพาะเมื่อผ่าน audit C2)
- U4: ฟอร์มมี 3 ช่อง (ชื่อ/อีเมล/ข้อความ) · ตัด dropdown ออก · placeholder "เล่าสั้น ๆ ว่าอยากคุยเรื่องอะไรครับ" · success = "ได้รับข้อความแล้วครับ" (ไม่สัญญาว่าจะตอบกลับ)
- U5: ลำดับ About = Bio ไม่เกิน 3 ย่อหน้า → ประโยคบอกว่าใครทำชั้นไหน → Interests แบบย่อ → CTA
- U6: บนมือถือ nav แตะง่าย · ปุ่มติดต่อเห็นโดยไม่ต้องเลื่อนจอบน Home
- U7: ตัวนับ "0/1000" ใต้ช่องข้อความ
- U8: ประโยค retention ใต้ฟอร์ม ระบุจำนวนวัน (เช่น 90 วัน)
- U9: error ทุกกรณีบอกทางเลือกถัดไป ห้ามแสดงรหัส/stack/SQL

## IA สุดท้าย
- Home: headline แสดงเป็น 2 ระดับในภาพ แต่ใช้ข้อความของ Brand ครบ + tagline + ปุ่มส้ม
- About: ตาม U5
- Interests: หน้าแยก (มี src/pages/interests.astro + GET /api/interests อยู่แล้ว) แสดง U1 แบบเต็ม · About แสดงแค่หัวข้อ พร้อมลิงก์ไปหน้า Interests
- Contact: 2 สถานะ — A (ค่าเริ่มต้น / 501): ซ่อนฟอร์ม แสดงช่องทางสำรอง · B: เปิดฟอร์มเมื่อเงื่อนไข R5/C4 ครบ

## สิ่งที่ยอม และเหตุผล
- ตัด dropdown (C3): ฟอร์มสั้นลงดีต่อ UX และตัดช่องที่ bot ใช้กรอก
- Home เขียนถึง recruiter เป็นหลัก: กลุ่มรองยังพิมพ์บอกเองในช่องข้อความได้
- Headline ใช้ข้อความ Brand ครบ: ขอแค่แยกระดับ font ให้กวาดตาได้บนมือถือ
- Interests กลับเป็นหน้าแยก (เดิมเสนอรวมเข้า About): route/API มีอยู่แล้ว ตัดทิ้งเปลืองกว่าเก็บไว้
- X2 เข้าข้าง Devil: ship แบบไม่มีช่องติดต่อเลย = journey หลักพัง

## session ถัดไปต้องเช็ก
- Contact สถานะ A: backend ตอบ 501 → ฟอร์มถูกซ่อน และแสดงช่องทางสำรองจริง
- จอ 360px: headline ไม่เกิน 2 บรรทัดต่อระดับ · ปุ่มติดต่อเห็นโดยไม่ต้องเลื่อน
