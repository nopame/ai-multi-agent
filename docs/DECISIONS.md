# Decisions — Personal Site

> Approved เท่านั้น · ที่มา: [`DEBATE.md`](DEBATE.md) (Brand / UX / Devil · 2 รอบ · 2026-09-25) · facilitator: Claude

## สรุปการโต้วาที

ทั้งสามบทบาทเห็นตรงกันว่าแกน "Full-stack developer ที่ใช้ AI agent อย่างมีระบบ" แข็งพอ แต่ข้อความปัจจุบัน overclaim (ตัวเลข "5 ปี" และ "ครบทุกชั้น" ที่ยืนเดี่ยว) และจุดขาย "ตรวจสอบได้" ยังไม่มีหลักฐานที่คนนอกกดตรวจเองได้ Brand ย้ายประโยคบทบาทเข้า Bio และทำ headline สองชั้น UX ล็อกลำดับ Home ให้ปุ่มติดต่อปุ่มเดียวอยู่ในจอแรกบนมือถือ และคง IA 4 หน้า Devil ทำให้ฟอร์ม Contact กลายเป็นเงื่อนไข ไม่ใช่ Must โดยมี gate ก่อนเปิดฟอร์มและก่อน ship ประเด็นที่ยังค้างมีเรื่องเดียวคือช่องติดต่อจริงที่ขัดกับกฎ Privacy ซึ่งตัดสินใน D11 และเจ้าของต้องลงมือเอง

### PROFILE ที่แก้ในรอบนี้

- `## Headline` → "Full-stack developer ที่วางระบบให้ทีม AI agent ส่งงานได้ตั้งแต่ UI ถึงฐานข้อมูล" (D1)
- ยังไม่แก้: Bio / Tagline (D3) · Interests (D5) · ลบ "5 ปี" (D2) · Privacy/Contact (D11) → ดู OPEN_LOOPS L6 / L9

## สิ่งที่เลื่อนออก (Out of scope v1)

- Guestbook (ทั้ง UI และการเปิดรับข้อความ) → Later
- Nice ทุกข้อ: แถบการ์ด 5 ชั้น · badge + สรุปผล test แบบ section · ส่วน "เว็บนี้สร้างยังไง" · หน้า Projects · โหมดมืด · section "สำหรับมือใหม่"
- ลิงก์ไป PR / issue รายตัวเพื่อใช้เป็นหลักฐาน
- dropdown หรือช่องเพิ่มเติมในฟอร์ม (มีแค่ 3 ช่อง)
- เพิ่ม `## Tagline` / `## Tone` เข้า parser
- Blog · หน้า Services · สองภาษา (เป็น Later อยู่แล้ว)
- เนื้อหาสำหรับกลุ่มรองบนหน้าแรก

## เกณฑ์พร้อม Frontend (Lab 04)

- `docs/PROFILE.md` ผ่าน D1–D3 และ D5 แล้ว: Headline ใหม่ · Role statement เป็นประโยคแรกของ Bio · Bio ≤ 3 ย่อหน้าและไม่มี "5 ปี" · ไม่มีหัวข้อ `## Tagline` · Interests อยู่ในรูป "หัวข้อ — ประโยคเดียว"
- สเปก Home ล็อกแล้วตาม D4: ปุ่มส้มปุ่มเดียวอยู่ในจอแรกที่ 360px · ไม่มีรายการ Audience · ลิงก์ "ดูโค้ด" เป็น slot ที่ปิดอยู่ (ไม่ฝัง URL)
- หน้า Contact รองรับ 501: ซ่อนฟอร์มแล้วแสดงช่องสำรอง · microcopy ตาม D9 · ไม่มี API path
- nav มี 4 หน้า ไม่มี Guestbook (D5) · ไม่มีช่องทาง "—" (D9)
- `npm test` เขียว รวมถึง guard test ที่กันข้อความคอร์สหลุด
