## Bio

สิ่งที่ทำให้ผมอยู่กับงานนี้มาได้นานคือการเรียนรู้เทคใหม่อย่างต่อเนื่อง ผมไม่ได้เรียนเพื่อรู้อย่างเดียว แต่นำมาลองกับงานจริงเสมอ เพื่อดูว่าอะไรช่วยให้ทีมส่งงานได้ดีขึ้นจริง

ตอนนี้ผมโฟกัสที่ AI agent และ multi-agent workflow และใช้เว็บนี้เป็นผลงานหลักที่แสดงแนวทางนั้น เว็บนี้สร้างโดยแบ่งหน้าที่ให้ agent แต่ละตัว (frontend / backend / reviewer) แล้วประสานงานกันผ่านเอกสาร issue และ pull request เหมือนทีมพัฒนาจริง ทุกการตัดสินใจจึงตรวจย้อนได้ใน repo

ถ้าคุณกำลังมองหา developer ที่เชื่อม full-stack เข้ากับการใช้ AI อย่างมีระบบ ยินดีคุยครับ
