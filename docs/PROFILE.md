## Bio
ผมช่วยทีมส่งเว็บที่ใช้งานได้จริงครบทุกชั้น ตั้งแต่หน้าเว็บ ฝั่ง server ฐานข้อมูล ไปจนถึงการนำขึ้นระบบ โดยวางระบบให้ AI agent หลายตัวทำงานร่วมกันเป็นทีมอย่างมีระบบ

ผมทำงาน full-stack มาหลายปี ผ่านหลายโปรเจกต์และหลายสแต็ก และนำเทคใหม่มาลองกับงานจริงเสมอ เว็บนี้คือตัวอย่างของแนวทางนั้น: frontend / backend เขียนโดย agent ภายใต้ spec และ review ของผม และทุกการตัดสินใจถูกบันทึกเป็นเอกสารก่อนลงมือ

ถ้าคุณกำลังมองหา developer ที่เชื่อม full-stack เข้ากับการใช้ AI อย่างมีระบบ ทักมาทางหน้าติดต่อได้เลยครับ
