## Bio
ผมเขียน spec และ review ทุก PR ส่วน agent แยกกันเขียน frontend และ backend ผมเป็น full-stack developer ที่ดูแลงานตั้งแต่หน้า UI, API ไปจนถึงฐานข้อมูล และวางระบบให้ทีม AI agent แบ่งหน้าที่กันชัดเจนโดยมีผมเป็นคนตัดสินใจสุดท้าย

เว็บนี้คือตัวอย่างงานของผม หน้าเว็บเขียนด้วย Astro ข้อมูลเก็บใน SQLite และทุกการเปลี่ยนแปลงต้องผ่าน test กับ CI ก่อน merge agent แต่ละตัวรับงานจาก issue แล้วส่งกลับมาเป็น pull request ให้ผม review

ถ้าทีมของคุณกำลังมองหา full-stack developer ที่ใช้ AI agent อย่างมีระบบ ติดต่อผมได้เลยครับ
